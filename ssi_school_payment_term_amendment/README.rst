==============================
School Payment Term Amendment
==============================

Master data for the reasons behind a payment term amendment, and the
Payment Term Amendment document itself: voiding a payment term line,
changing its unit price, or adding a line or a whole payment term on an
open or done enrollment, as long as the targeted term or line has not
been invoiced yet. One document amends one enrollment and the change
only takes effect once the document is approved. This is not a billing
reduction: a voided line keeps its original price and merely stops
being billed. There is no reversal after the document is done.

Installation
============

To install this module, you need to:

1.  Clone the branch 14.0 of the repository https://github.com/open-synergy/ssi-school-payment-term-amendment
2.  Add the path to this repository in your configuration (addons-path)
3.  Update the module list (Must be on developer mode)
4.  Go to menu *Apps -> Apps -> Main Apps*
5.  Search For *School Payment Term Amendment*
6.  Install the module
